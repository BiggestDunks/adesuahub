# Adesua Hub

Adesua Hub is a web app designed to help Ghanaian students prepare for exams with dynamic content, Firebase authentication, and subject-based quizzes.

## 🔧 Tech Stack
- React
- Firebase Auth
- React Router
- Ghana Education APIs

## 🚀 Features
- Login/Register with Firebase
- Protected Dashboard
- Subject Pages (Math, Science, etc.)
- Quiz Engine (WASSCE-style)

```bash
npm install
npm start
